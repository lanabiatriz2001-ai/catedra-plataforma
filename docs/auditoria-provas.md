# Auditoria dos textos de prova (discursivas e espelhos)

Gerado por `node scripts/auditar-provas.mjs --md docs/auditoria-provas.md`. Cada id abaixo tem
texto publicado com defeito detectável e precisa ser **reprocessado a partir do
PDF original** (ou rebaixado para "somente link" até lá — texto errado é pior
que ausente).

- Enunciados extraídos: **561**, reprovados: **267**
- Espelhos embutidos: **78**, reprovados: **59**
- Provas **sem espelho nenhum**: **570** — doença separada: falta extrair
  dos PDFs de espelho (ou a banca não publicou; nesse caso, dizer isso na tela).

## Receita de correção (no build-provas-conteudo.mjs, onde estão os PDFs)

1. **Cortar a capa/instruções**: descartar tudo antes do primeiro marcador real
   da prova (ex.: "Sentença", "QUESTÃO", "Considerando a situação hipotética"),
   e qualquer página que case com "NÃO SERÁ PERMITIDO / INFORMAÇÕES GERAIS".
2. **Remover cabeçalho/rodapé**: linha que se repete em 3+ páginas do mesmo PDF
   é moldura, não conteúdo — remover por frequência antes de juntar as páginas.
3. **Espelho em tabela**: extrair com `page.find_tables()` do PyMuPDF (e juntar
   célula a célula), nunca com `get_text()` cru.
4. **PDF escaneado** (texto < 300 chars): OCR (`fitz` + Tesseract) ou rebaixar a
   prova para "somente link", com aviso honesto na tela.
5. **Portão de qualidade**: rodar `auditar-provas.mjs --portao` no fim do build —
   prova que reprovar NÃO publica texto.
